מעבר מ-ZHA ל-Zigbee2MQTT

ZHA הוא ה-Zigbee המובנה של Home Assistant. ZigDash עובדת עם Zigbee2MQTT, ולכן היא לא יכולה להציג מכשירים שנמצאים ב-ZHA. מעבר פירושו לצמד מחדש את המכשירים שלכם עם Zigbee2MQTT. אחר כך Home Assistant ממשיך להשתמש בהם, דרך שילוב ה-MQTT שלו.

לפני שמתחילים

  • איזו התקנה? אם בתפריט הגדרות של Home Assistant מופיע Apps (Add-ons בגרסאות ישנות), יש לכם Home Assistant OS: ראו עם אפליקציות. אם לא, Home Assistant רץ ב-Docker (Container): ראו Docker.
  • איזה מתאם? פתחו את הגדרות › מכשירים ושירותים › Zigbee Home Automation. תחת Hubs, המתאם מופיע לפי הדגם שלו, למשל SONOFF ZBDongle-E. אחר כך בדקו את המתאם שלכם.
  • גבו את ZHA. באותו עמוד, הקישו על ⚙ ליד Zigbee Home Automation, ואז על Download backup. שמרו את הקובץ. ב-Network information באותו עמוד מופיעים הערוץ, סוג הרדיו והיציאה הטורית.
  • מה משתנה ב-Home Assistant. המכשירים שלכם חוזרים כמכשירי MQTT חדשים, עם מזהי ישויות (entity IDs) חדשים. צריך לכוון אל המכשירים החדשים את האוטומציות, הסקריפטים ולוחות המחוונים שמשתמשים בהם, וההיסטוריה שלהם מתחילה מחדש. קבוצות וקישורים (bindings) שנוצרו ב-ZHA יוצרים מחדש ב-Zigbee2MQTT.
  • זמן. כל מכשיר מאופס ומצומד מחדש, אחד אחרי השני. עדיין אין לנו הערכות זמן אמינות; תכננו ערב לבית קטן, ויותר לבית גדול.

מתאם שני

  1. התקינו את Zigbee2MQTT על המתאם החדש (עם אפליקציות או Docker) עם רשת משלו. בחרו את כל זה לפני ההפעלה הראשונה של Zigbee2MQTT, כי שינוי הערוץ מאוחר יותר עלול לחייב צימוד מחדש:
    • השאירו את מפתח הרשת ואת ה-PAN ID על GENERATE (ברירת המחדל);
    • בחרו ערוץ שונה מזה של ZHA (הוא מופיע ב-⚙ של ZHA › Network information); Home Assistant ממליץ על 15, 20 או 25.
  2. הרחיקו את שני המתאמים זה מזה, כל אחד על כבל מאריך USB.
  3. ב-Home Assistant OS, כשמחברים את המתאם החדש, Home Assistant עשוי להציע להגדיר אותו ל-ZHA או ל-Thread. התעלמו מזה: המתאם מיועד ל-Zigbee2MQTT.
  4. העבירו חדר אחד בכל פעם: צמדו קודם את המכשירים שמחוברים לחשמל (נורות, שקעים, מתגים בקיר: הם נתבים), ואחר כך את המכשירים על סוללה.
  5. כשכל המכשירים הועברו, השביתו את ZHA (ראו בהמשך) ושמרו את המתאם הישן כרזרבה.

אותו מתאם

  1. הורידו את הגיבוי של ZHA (ראו לפני שמתחילים), ממש לפני שמתחילים.
  2. השביתו את ZHA: הגדרות › מכשירים ושירותים › Zigbee Home Automation, ה-⋮ ליד Zigbee Home Automation › Disable. לא Delete.
  3. התקינו את Zigbee2MQTT על אותו מתאם (עם אפליקציות או Docker), והשאירו את מפתח הרשת ואת ה-PAN ID על GENERATE.
  4. כבו את מכשירי ה-Zigbee שמחוברים לחשמל, במתג שבקיר או בלוח החשמל. אחרת הם ממשיכים לחפש את הרשת הישנה.
  5. הדליקו אותם בחזרה אחד אחד, וצמדו כל אחד כשהוא נדלק. אחר כך צמדו את המכשירים על סוללה.

המתאם שלכם

  • Silicon Labs (Home Assistant Connect ZBT-1 ו-ZBT-2, Home Assistant Yellow, Sonoff ZBDongle-E, SMLIGHT SLZB-06M ו-SLZB-07): adapter: ember. ה-ZBT-2 צריך גם baudrate: 460800; ה-ZBDongle-E צריך rtscts: false; ה-SLZB-06M צריך קושחה 20240510 או חדשה יותר.
  • Texas Instruments (Sonoff ZBDongle-P, SMLIGHT SLZB-06 ו-SLZB-06P7): adapter: zstack.
  • ConBee או RaspBee: adapter: deconz.
  • CC2531 או ZiGate: ישנים מדי, או שכבר לא מתוחזקים, בשביל רשת Zigbee2MQTT טובה. השתמשו בדרך של מתאם שני, עם מתאם חדש.
  • מתאם רשת (SMLIGHT SLZB-06, SLZB-06M, SLZB-07, MR series): ZHA מציג אותו כ-socket://IP:6638; ב-Zigbee2MQTT הוא tcp://IP:6638, וב-Docker אין צורך בשורת USB.
  • Multiprotocol (ZBT-1 או Yellow שמריצים Zigbee ו-Thread יחד; עמוד החומרה ב-Home Assistant מציין את זה): Zigbee2MQTT לא יכול להשתמש בקושחת multiprotocol. בדרך של אותו מתאם, כבו את ה-multiprotocol כשעדיין נמצאים ב-ZHA, לפי הנוהל של Home Assistant עצמו (ZBT-1, Yellow). מכשירי Thread שהשתמשו בו מפסיקים לעבוד עד שנתב גבול (border router) אחר של Thread לוקח אותם. בדרך של מתאם שני, אל תיגעו בו, וקנו את המתאם החדש כ-Zigbee בלבד.

בעמודי המתאמים של Zigbee2MQTT יש את כל הפרטים.

Home Assistant עם אפליקציות (Home Assistant OS)

  1. בתפריט הגדרות › Apps, התקינו והפעילו את Mosquitto broker. אז Home Assistant מציע את שילוב ה-MQTT תחת הגדרות › מכשירים ושירותים: אשרו אותו.
  2. הוסיפו את המאגר של Zigbee2MQTT (בחנות האפליקציות, ⋮ › Repositories: https://github.com/zigbee2mqtt/hassio-zigbee2mqtt), ואז התקינו את Zigbee2MQTT.
  3. בלשונית Configuration שלו, הגדירו את היציאה הטורית ואת המתאם לפי המתאם שלכם, למשל: 
    port: /dev/serial/by-id/usb-...
adapter: ember
    בדרך של מתאם שני, הגדירו גם את הערוץ (ראו למעלה) לפני ההפעלה הראשונה.
  4. הפעילו את Zigbee2MQTT ופתחו את דף האינטרנט שלו מהעמוד של האפליקציה. ואז צמדו.

Home Assistant ב-Docker (בלי אפליקציות)

בלי אפליקציות, Mosquitto ו-Zigbee2MQTT רצים כקונטיינרים נפרדים לצד Home Assistant. בתיקייה חדשה:

1. compose.yaml (שימו את הנתיב של המתאם שלכם ב-devices; ls /dev/serial/by-id/ מציג אותו):

services:
  mosquitto:
    image: eclipse-mosquitto:2
    restart: unless-stopped
    ports:
      - 1883:1883
    volumes:
      - ./mosquitto/config:/mosquitto/config
      - ./mosquitto/data:/mosquitto/data
  zigbee2mqtt:
    image: ghcr.io/koenkk/zigbee2mqtt
    restart: unless-stopped
    depends_on:
      - mosquitto
    ports:
      - 8080:8080
    volumes:
      - ./zigbee2mqtt:/app/data
      - /run/udev:/run/udev:ro
    environment:
      - TZ=Europe/Berlin
    devices:
      - /dev/serial/by-id/usb-...:/dev/ttyACM0

עם מתאם רשת, השמיטו את devices ואת שורת ה-udev.

2. mosquitto/config/mosquitto.conf:

listener 1883
allow_anonymous false
password_file /mosquitto/config/passwd
persistence true
persistence_location /mosquitto/data/

צרו את משתמש ה-MQTT (תתבקשו להזין סיסמה פעמיים; הקובץ חייב להיות שייך למשתמש של Mosquitto עצמו, אחרת Mosquitto לא יעלה):

docker run -it --rm -v "$PWD/mosquitto/config:/mosquitto/config" eclipse-mosquitto:2 \
  sh -c "mosquitto_passwd -c /mosquitto/config/passwd zigbee && chown mosquitto:mosquitto /mosquitto/config/passwd"

3. zigbee2mqtt/configuration.yaml (שורות המתאם לפי המתאם שלכם):

homeassistant:
  enabled: true
frontend:
  enabled: true
  port: 8080
mqtt:
  server: mqtt://mosquitto:1883
  user: zigbee
  password: your-password
serial:
  port: /dev/ttyACM0          # a network adapter: tcp://IP:6638
  adapter: ember
advanced:
  network_key: GENERATE
  pan_id: GENERATE
  ext_pan_id: GENERATE
  channel: 20                 # second adapter: not ZHA's channel

4. בדרך של אותו מתאם, ZHA כבר מושבת עכשיו (ראו למעלה). אם הקונטיינר של Home Assistant עצמו ממפה את המתאם, הסירו את השורה הזו מקובץ ה-compose שלו או מ-docker run: רק קונטיינר אחד יכול להשתמש במתאם.

5. docker compose up -d, ואז פתחו את http://the-machine:8080: דף האינטרנט של Zigbee2MQTT.

6. ב-Home Assistant: הגדרות › מכשירים ושירותים › Add integration › MQTT. Broker: כתובת ה-IP של המחשב, פורט 1883, משתמש zigbee והסיסמה.

צימוד המכשירים

  1. בדף האינטרנט של Zigbee2MQTT, הקישו על Permit join (פתוח לכארבע דקות). כדי לצמד דרך נתב שקרוב למכשיר, בחרו את הנתב הזה בתפריט של permit join: שימושי ל-Aqara ולמכשירים בררניים אחרים.
  2. אפסו את המכשיר למצב צימוד, כמו שהיצרן מורה: לחיצה ארוכה ברוב החיישנים, כמה מחזורי הדלקה וכיבוי בנורות, סדרה של הקשות על המתג בחלק מהמתגים שבקיר.
  3. כשהוא מופיע, תנו לו שם וחדר ב-Zigbee2MQTT. ואז עברו לבא בתור.

קודם המכשירים שמחוברים לחשמל, אחר כך המכשירים על סוללה, כדי שלרשת החדשה יהיו מסלולים.

אחרי המעבר

  • ZigDash: פתחו אותה והקישו על מצאו את ההתקנה שלי. היא מוצאת את Mosquitto ברשת שלכם; התחברו עם משתמש ה-MQTT. או בחרו Home Assistant והתחברו: גם זה עובד עכשיו, כי ל-Home Assistant יש את שילוב ה-MQTT.
  • שמות וחדרים: ב-ZigDash, הגדרות › ייבוא מ-Home Assistant מביא את השמות והחדרים שנתתם למכשירים החדשים ב-Home Assistant.
  • Home Assistant: כוונו את האוטומציות, הסקריפטים ולוחות המחוונים אל המכשירים החדשים. כשאתם בטוחים, מחקו את שילוב ה-ZHA.

חזרה אחורה

  • מתאם שני: עצרו את Zigbee2MQTT ונתקו את המתאם החדש. ZHA אף פעם לא הפסיק לעבוד. מכשירים שכבר העברתם צריך לצמד מחדש ל-ZHA.
  • אותו מתאם: עצרו את Zigbee2MQTT, ואז בעמוד של ZHA הקישו על Enable. ZHA מציג "Network settings do not match most recent backup" (הגדרות הרשת לא תואמות לגיבוי האחרון), כי המתאם מחזיק עכשיו את הרשת של Zigbee2MQTT. פתחו את הגדרות › Repairs › "Zigbee network settings have changed" (הגדרות רשת ה-Zigbee השתנו) ובחרו Restore backup (recommended). הרשת של ZHA חוזרת כמו שהייתה. מכשירים שצימדתם ל-Zigbee2MQTT צריך לצמד מחדש ל-ZHA. אם לא מופיע תיקון, השתמשו ב-⚙ › Migrate adapter עם הגיבוי שהורדתם.
נבדק: ב-17 בנובמבר 2026, עם Home Assistant 2026.11 ו-Sonoff ZBDongle-E, הרשת של ZHA חזרה בדיוק כמו שהייתה (ערוץ, PAN ID ומפתח רשת). עדיין לא בדקנו את זה עם מכשירים מצומדים, אז שמרו את קובץ הגיבוי.

שמירת הרשת בלי צימוד מחדש

יש דרך שלישית: להעתיק את הרשת של ZHA אל Zigbee2MQTT, כך שלא צריך לצמד מחדש את המכשירים. Zigbee2MQTT לא תומך בזה, ערך שגוי עלול למחוק את הרשת, וזה הגיוני רק בבתים גדולים (נגיד, מעל 60 מכשירים). אם תרצו לקרוא על זה: התשובה של המתחזק של Zigbee2MQTT, ודיווחים מהקהילה בדיון 24478 ובדיון 26716.

ספרו לנו איך הלך. המדריך הזה חדש. אם שלב היה שגוי או חסר, כתבו ל-support@zigdash.app או לקהילה.
