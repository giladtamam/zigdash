Setup now asks which SMLIGHT device you have. An SMHUB runs Zigbee2MQTT itself, so ZigDash looks for the hub. An SLZB adapter is only the Zigbee radio, so ZigDash asks where Zigbee2MQTT runs: Home Assistant, or a Raspberry Pi, server or Docker. When an SMHUB's broker asks for a login, setup now says you can turn on Allow Anonymous instead. Older SMHUBs that show their web page on port 3000 are found too.
